# 低ノイズ後処理のクラスタ内完結

所有者の指示に従い、C3T2索引後の条件別集約・算術照合・候補入力作成・全12条件比較・独立計時・日本語報告の待受をクラスタに移す。
科学計算の設定・seed・分母・失敗の扱い・既存の受入条件を変更しない。
このPC上の稼働中制御と新しい制御の二重投入を防ぎ、旧制御の識別情報・未投入状態・停止記録を保存する。
既存の科学計算sourceは無変更で使用し、クラスタ上の既存ファイルをローカルファイルとして読むtransportのみを分離する。
従来の`ssh cluster`による制御呼出しは同じ引数・環境・標準入出力を使うクラスタ内呼出しへ置き換え、`scp cluster:`は検証済みの同一ホスト内コピーへ置き換える。
別host・曖昧な引数・上書き・想定外の操作を拒否する。
元の入力記録は保存し、Windowsパスの移設が必要な派生記録は元hashと対応表を別に持つ。
ローカルで実行したようにremoteの記録を偽装しない。
重い索引・照合・集約・比較・計時・報告処理はqsubで投入し、要求ノード数は待機・保留を含めて最大2とする。
軽い待受とPBS状態照会はクラスタ側で独立した制御プロセスとして継続し、PCのSSH接続や再起動に依存させない。
timeoutや接続断は終了とみなさず、同じジョブIDと保存済み投入記録を照合する。
本番投入を伴う不確実な応答は自動再試行せず、記録を保存して停止する。
全12条件が揃うまで正式比較へ進めず、資源規則で通常経路が不可能なら同じ12条件を分割経路で処理する。
受入には同一ホストtransportの引数・環境・標準入力・終了コードの一致、対象外hostの拒否、上書き拒否、段階間のhashと条件照合、投入済みジョブの再投入拒否を含める。
完了確認は各段階の正式な終端記録と最終報告の実体に基づき、waiterの起動成功だけを全工程の検証済み状態とは扱わない。

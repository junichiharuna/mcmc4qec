# 最終集約後の後処理復旧

最終集約は正常終了したが、算術照合の再現資料保存時に受入ログが欠けて停止した。
科学計算の設定、既存ソース、完了済み集約、失敗記録を変更しない。
不足した5ログは既存の受入記録にあるサイズ・SHA-256と照合して追加する。
ログが不足・改変されている場合は再照合を開始しない。
既存の算術照合出力は保持し、新しい出力先で元の照合プログラムをqsubにより実行する。
受入テストもPBS内で実行し、ローカルPCでは計算ジョブを実行しない。
作成済みの比較用候補はmanifest、条件、環境、collection receipt、元の入力との対応を確認して再利用する。
新しい照合が正常終了し、出力manifestを検証した場合に限り、全12条件比較・独立計時・報告の既存手順へ接続する。
旧controllerの終了と旧算術ジョブの失敗を照合し、新しいjournalへ復旧の経緯を保存する。
qsubは共有lockと最大2ノードの既存投入処理を使い、通信の観測失敗だけで再投入しない。
結果の公開用記録ではホスト名を省き、ホームディレクトリを`$HOME`へ置換する。
置換した記録の原本SHA-256は置換前の原本を指すと注記する。

受入条件は、完全なログ束の受理、不足ログ・改変ログ・不正な相対パスの拒否、旧受入テストの成功、新しい算術照合の正常終了である。
計算の正常終了を精度、混合、名目95%被覆の保証とは扱わない。

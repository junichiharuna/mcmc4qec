# C3T2の復旧後続経路

DGXの入力確認停止を受けて終了したindex・distribution・最終準備・最終実行・最終回収の5待受を対象とする。
各待受の実PID不存在、想定した依存失敗、処理未着手のディレクトリ内容と元pinを確認する。
distributionのlabo共通入力回収のみ完了済みなので、受理記録と各ファイルを照合して再利用する。
DGX serialと親待受、index、distribution、最終3段階の参照を新しい復旧先へ明示的に変更し、それ以外の入力・科学helper・分母・設定は維持する。
元の停止記録を残し、新しい記録に元の証拠と復旧sourceのhashを保存する。
元のqsub実行・最大2要求nodeの共有lock制御を継承し、復旧のための数値再投入や自動再試行は行わない。
最終算術検証のdistribution_doneも新しい完了記録に結び、canonical候補の出力先は維持する。

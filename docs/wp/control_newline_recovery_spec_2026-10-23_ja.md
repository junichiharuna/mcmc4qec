# 制御仕様書の改行差分による停止の復旧

2026年10月23日にC3T1 laboのserial回収完了後、親の固定入力検証が停止した。
唯一の不一致はfuture_pc_export_wait_spec_2026-10-22_ja.mdのLFからCRLFへの変換であり、CRLFをLFへ戻したバイト列が既存intentのSHA256と完全一致することを確認した。
変換前のバイト列とhashを保存し、既知の変換前hash・変換後hashの両方に一致する場合だけ仕様書を復元する。
本文の変更、科学設定の変更、稼働中コードの変更、数値計算の再投入は行わない。
停止した親と後続は、停止記録を保持し、元の成果物と全固定入力を検証して新しい復旧記録へ接続する。
正常終了したserialは再起動せず、全割当の回収証拠を元の検証契約で検証する。
実稼働中のDGX serial、C3T2 native・PC待受、クラスタsamplingは保持する。
未知の入力変更、失敗種別、追加の処理試行、成果物の不一致は自動的に受理しない。
復旧の受入は科学的な収束や被覆の認定ではない。

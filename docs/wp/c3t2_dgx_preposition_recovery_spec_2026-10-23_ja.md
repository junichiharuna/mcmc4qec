# C3T2 DGX入力確認タイムアウトからの継続

対象はtile288 depolarizing、p=0.001のDGX batch0であり、転送後のhash確認SSHが90秒で終了せず、serialと依存待受が停止した。
元の停止記録・入力・科学計算helperは変更しない。
実プロセスの不存在、14個の転送済みファイルの完全一致、元の入力とsource pinの不変性を確認してから、未作成のpreposition受理記録を復旧の証拠付きで追加する。
exportとprepositionは既存の検証済み入力を再利用し、parityから元の全33バッチの順序・設定で継続する。
新しいserialと親待受は別ディレクトリに記録し、自動再試行とqsubを行わない。
元の停止記録を成功に書き換えず、後続待受は検証済みの復旧先を明示して接続する。
受入試験では、入力欠落・hash不一致・実行中プロセス・対象外の停止・元pin変更を拒否し、全バッチと元の科学的処理順序が保持されることを確認する。
ローカル受理後も既存stageが転送済みファイルのhashとruntimeを再確認する。

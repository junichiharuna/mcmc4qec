# 低ノイズ独立計時のMC/BAR費用比較（精度正規化、2026-10-29）

本稿は独立計時の最終report（`report.json`、SHA-256 `79d1357d…`、2026-10-29 02:21 JST受理）の`records`から転記した値で、12選択条件のMCとBARの費用を達成精度で正規化して比較する。
凍結report scriptの費用比は両手法が経験的精度gate（相対RMSE ≤ ε）を通った条件にだけ出る規則で、12条件中3条件にしか値がない。
所有者は2026-10-29に、凍結reportの値と規則は変えず、論文（RIMC）の「目標精度に達するまでの時間」と同じ趣旨の正規化量を別に定義して全12条件を示す方針を選んだ。
再実行は行わない。
数値の再計算は正規化の算術だけで、raw datasetの再読込や新しい科学計算は行っていない。
原本の写しと抜粋は`data_tile_validation_2026-10-17/low_noise_final_report_2026-10-29/`（`condition_summary.json`、`normalized_comparison.json`）にある。

## 定義

条件（符号・p・ε）と手法（MC・BAR）ごとに、192反復のtask費用の平均をC、有限WSS reference区間に対する相対RMSEの範囲の中点をr、相対biasの範囲の中点をbとする。
精度正規化した費用を次で定義する。

- C_ε(r) = C × (r / ε)²
- C_ε(s) = C × (s / ε)²、ただし s = √(r² − b²)（予算で減らせる分散成分だけを数える）

正規化比はMCのC_εをBARのC_εで割った値で、1より大きければBARが安い。
この定義は、相対誤差が費用の平方根に反比例して減るという仮定（独立標本のMCでは成り立ち、BARでは反復や鎖の追加で予算を増やす場合に対応する）に依存する。
BARのbiasは予算を増やしても減らないので、bがrに対して無視できない条件ではC_ε(r)とC_ε(s)が離れ、どちらも目標精度εに達する費用の保証にはならない。
rの範囲幅はreference区間の幅に由来し、12条件とも中点の1%未満である。
反復間のばらつきに基づく標準誤差は、per-replicateの記録（各実行rootの`summary.json`）をbootstrapすれば求められるが、本稿では未実施である。
192反復のRMSE推定の相対標準誤差は正規近似で1/√(2×192) ≈ 5.1%、(r/ε)²では約10%であり、正規化比の有効数字はこの程度と見る。
反復の誤差分布が正規より裾の重い場合はこれより大きい。

## 読み取り

- p=0.01の4条件では直接MCがBARより安い。正規化比は0.17〜0.57で、case 0・ε=0.2ではMCが約5.6倍安く、かつMCだけがgateを通っている。
- p=0.003の4条件ではBARが2.1〜4.7倍安い。
- p=0.001の4条件ではBARが10〜35倍安い。
- したがってクロスオーバーはtile72の2つのnoiseでp=0.01と0.003の間にあり、RIMC論文が12符号で報告した「高いpでは直接MC、rare-event領域でsplitting」という描像と整合する。
- MCの相対biasはすべて|b| < 0.03で、MSEに占める割合は2%以下である。BARは多くの条件で同程度だが、case 2・p=0.001・ε=0.2では相対bias −0.143がMSEの48%を占める。この条件の正規化比はbiasを数えるかどうかで9.7と18.8に分かれ、予算を増やしてもgateを通る保証はない。同条件のBARの被覆は151/192で12条件中最低である。
- BARの被覆は151〜176/192で名目95%に届かず、独立計時では混合診断を取得していない。正規化比はBARの区間の過小被覆を補正しない。
- 正規化比の有効数字は約2桁であり、反復間のbootstrapによる標準誤差は未算出である。

## 適用限界

- 凍結reportの費用比はgate規則を含めてそのまま保持し、本稿の正規化比を凍結reportの値として引用しない。
- 正規化はtask費用だけを対象にし、capacity計測・seed監査・選択・報告処理の費用、PBSのwalltime、partition・hostの差は含まない。
- 相対RMSE・biasは有限WSS reference区間に対する値で、区間を真値と同一視しない。
- BARの費用がεに対してMCと同じ指数で伸びることは未検証であり、C_εはεを変えたときの実測費用の予測ではない。
- 本稿の値を「BARはMCより2〜30倍速い」と要約する場合は、p=0.003以下のtile72に限ることと、p=0.01ではMCが安いことを併記する。

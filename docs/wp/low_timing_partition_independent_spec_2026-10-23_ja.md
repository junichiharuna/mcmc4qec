# 分割集約後の独立計時への接続

分割経路のseed censusが完了した後、既存の独立計時計画・capacity準備・qsub実行処理へ接続する。
計画の全24組合せ・MC/BARの48行、capacity各2反復、本計測各192反復、選択基準を変更しない。
通常経路が選ばれた場合、分割専用の準備・実行待受は投入せず終了する。
対象がゼロの場合は48行を保存し、新しい計時を行ったと主張しない。
準備と実行のlocal journal・remote config・制御rootを通常経路から分離する。
科学計画が指す実行bundleとcapacity rootは既存仕様を維持し、既存rootを上書きせず排他的な準備を使う。
分割経路の開始は既存guardによる通常経路の未投入確認を前提とする。
既存の共有lock・qsub・最大2要求node・観測障害時の同一job追跡を維持する。
受入試験は通常経路選択、上流失敗、対象ゼロ、48行保持、計画の不整合拒否、投入応答不明時の非再投入を含む。
試験用PBS応答での成功と本番計時の完了を区別する。

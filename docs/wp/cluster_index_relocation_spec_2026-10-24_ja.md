# C3T2索引のクラスタ移設

所有者の2026年10月24日の指示により、途中保存のないローカル索引とその後続待受を停止し、同じ38バッチをクラスタで再検証する。
旧journal・入力・科学計算sourceを変更しない。
移設manifestに元のWindowsパス、元hash、実行先パス、取得元を記録し、registryだけを明示的に再配置する。
数値推定、decoder、BAR、bootstrapを再実行せず、既存のcohort_index.snapshotをバッチごとに無変更で実行する。
qsubで1ノード・8CPU・32GB・24時間を要求し、同時に最大8バッチを検証する。
投入は既存の共有lockを使用し、所有者の待機・実行ジョブを合わせた要求ノード数が2以内であることを確認する。
各バッチの索引は元の全768群を保持し、割当群だけが終端、他群はpendingであることを集約時に検証する。
全38バッチの重複・欠落・異なるcondition・異なるsource・変更された入力・未定義診断の脱落を拒否する。
集約は768群・67,584予定行の分母を保持し、失敗群と未定義診断も残す。
元registryと各再配置registryおよびバッチ索引のhashを来歴として残し、remoteの実測結果をローカルで実行したと表示しない。
受入では正常な分割集約、欠落、重複、割当外の終端群、異なるcondition、source不一致、分母不一致を検査する。
本番の完了判定はPBS終端、終了コード0、全バッチ成功と集約結果の照合による。
旧後続待受は自動再開せず、remote索引を用いる後処理の接続を別途検証する。

# portable reader の PBS 終端比較修正

2026-10-25 の実行では、portable reader が読み出し前後の `qstat -x -f -F json` 全体を比較し、観測時刻を表す最上位 `timestamp` の変化だけでも失敗していた。
index 2 のジョブ 265567 と index 3 のジョブ 265568 で、この例外による終了を確認した。
対象は index 2・3・4・5・9・10・11 の 7 条件であり、動作中の index 0・1・6・7・8 は置換対象に含めない。

## 許可する変更

`load_complete` 内の `current(job)` にある一つの比較式だけを置換する。
比較から除くのは返却 JSON の最上位 `timestamp` キーだけである。
`Jobs` 内の全フィールド、入れ子の `timestamp`、サーバー・バージョン・未知の最上位フィールドは引き続き比較する。
返却する元の JSON オブジェクトと `seen` に保存する全体の JSON deep copy は変更しない。
観測時刻の値に新たな型制限を追加しない。
計算式、数値データ、条件、seed、sampling、decode、推定処理は変更しない。

修正版 reader と既存バイト列を保持した CLI を、条件ごとの新しい二ファイル専用ディレクトリへ配置する。
環境の差分はその二モジュールの source hash・resolved source・import origin と、専用ディレクトリの `pythonpath` 先頭追加だけに制限する。
元と修正版の外部 SHA-256 pin を照合し、一行の変換を再生成して一致を検証する。
元の失敗記録・実行環境・ジョブ記録は残す。

## 受入結果

ジョブ 265581 と 265582 を、異なる二つの既定ノードに `qsub` で投入した。
既存の物理ノード上限判定を使い、各ジョブは 2 CPU・4 GB を要求した。
265581 は 22 秒、265582 は 21 秒で `F`・終了コード 0 になった。
それぞれで 17 件のメタデータ受入テストが成功した。
対象の実ソース全 7 件について、変更箇所以外の AST と正確なバイト変換、環境の限定差分を確認した。

各ノードで 7 条件の実 CLI を `-i --help` として起動し、その同じインタープリタで元の `bootstrap` を呼び出した。
`sys.path[0]`、実 CLI ファイル、引数、全 import origin、環境の source pin を確認した。
CPython の対話モードで失われる `__file__` だけを、検証した実 CLI の関数定義元へ復元した。
検索パスや科学計算の関数を差し替えた検証ではない。

各条件の元の終端ジョブを 1.1 秒以上空けて二回問い合わせ、返却された生 JSON をそのまま保存した。
全 7 条件・両ノードで、差分は最上位 `timestamp` だけだった。
実ソースから取り出した元の `current` はこの組を拒否し、修正版は受理して元の全 JSON オブジェクトをそのまま返した。
この試験では科学データ全体の読み出しや推定計算を実行していない。
したがって、受入結果は実 CLI の起動とメタデータ比較の検証であり、本計算の完走または数値結果の検証とは区別する。

## 監査範囲と証跡

portable snapshot 側の比較は元から job の正規化フィールドに限定され、別の全観測 JSON 比較は残っていないことを確認した。
recovered の 2 条件では、既に承認した producer の安定した終端表現を `observe` が返すため、今回の変更を加えない。
staged の 3 条件は pin 済みの終端記録を読み、動的な `qstat` 全体の再比較を行わない。

変換・テスト・probe・配置コードは private `output/portable_terminal_comparison_v1/` にある。
変換ソースの SHA-256 は `fdf0600e680204d6cb72e517952370ad582cbb676d1c4f681d1f98dedd431ee9` である。
実行入力、両ジョブの投入・終端記録、全 CLI ログ、全生 `qstat`、受入結果の原本 80 ファイルを private `output/portable_terminal_acceptance_collection_v1/` に回収した。
この文書には個人パスやノード名を記載せず、private 原本の SHA-256 とジョブ番号で対応を保持する。

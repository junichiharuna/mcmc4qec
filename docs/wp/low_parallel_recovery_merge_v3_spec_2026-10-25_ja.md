# recovered readerのCLI配置を含む環境契約

c0t0・c0t1のreader環境だけで、承認済みobserve修正と、tile_low_noise_timing_reader_cli.pyの同一bytesの移設を許す。
比較基準は元のreader環境であり、途中で失敗した環境や結果を基準として読み替えない。
環境規則へcli_before・cli_afterの外部pinを追加し、SHA-256と実bytesの一致を確認する。
新CLIと修正版recovered readerは同じ新ディレクトリに置き、そのディレクトリを元のPYTHONPATHへ一度だけ先頭追加する。
source_sha256・resolved_sources・import_originsでは、その2モジュールの旧pathを新pathへ置換する差分だけを許す。
Python実体・native binding・runtime・bundle・他の科学計算ソースと、環境の他の全フィールドを保持する。
recovered readerの変更は既存契約と同じobserve関数の委譲だけで、CLI自体の変更やその他の環境差分は拒否する。
全12条件の行検証、staged条件の歴史的pin補完、実行証跡検証、合流自身のPBS封印契約は維持する。
受入は小さな環境差分テストと12workerの結合テストをqsub内で行い、実際のCLI import検証と本番canaryの結果を別に記録する。

修正後のqsub受入ジョブ265557はF・終了コード0で完了し、59テストが8.83秒で成功した。
初回のfixtureではCLIの短縮名を使っていたため、実モジュール名tile_low_noise_timing_reader_cliへ合わせて別の受入ディレクトリで再検証し、初回のbytesは本番へ配置していない。
12件の環境差分テストに加え、c0t0・c0t1の新規則を含む12workerの結合と元の科学的検証を合成証跡で確認した。
受入済みbytesの本番用コピーと外部pinを保存し、ローカルではテストを実行していない。
公開用の受入証跡と元データ・保存データのhashは[reader_cli_merge_acceptance_20261025_v2](data_tile_validation_2026-10-17/reader_cli_merge_acceptance_20261025_v2/receipt.json)に保存する。
この受入は、実環境の子CLI起動や本番の再読込・合流が完了したことを意味しない。

# Results and diagnostics

`Result` represents an exact, MC, or conditional sampling run; `EstimationResult` summarizes an entire BAR ladder. Detailed trace diagnostics concern observable means, while BAR intervals concern logical error probabilities. Read the [statistical conventions](../api_en.md#default-statistical-errors-and-optional-detailed-diagnostics) alongside these fields and methods.

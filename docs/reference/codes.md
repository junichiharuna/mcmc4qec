# Codes and decoders

Factories construct validated CSS matrices. Decoder constructors build decoders that predict logical observables; adapters explicitly declare whether an external decoder returns corrections or observables. See the [workflow guide](../guide_en.md#choose-the-experiment-and-dependencies) for optional dependencies and the [custom decoder example](../tutorial_en.md#your-physical-correction-decoder) for output semantics.

# Sampling and estimation

Use `exact` for enumerable checks, `direct_mc` for independent trials, `sample_faulty` for a failure-conditioned distribution, and `estimate_logical_error` for anchored BAR splitting. The [tutorial](../tutorial_en.md#bar-with-default-settings) explains sampling budgets; the [API contracts](../api_en.md#bar-uncertainty) define error estimates and their limitations.
